# JavaScript Learning Journey

A comprehensive step-by-step guide to learning JavaScript from basics to advanced concepts.

## What's This Repository?

This repository contains beginner-friendly JavaScript tutorials that break down complex concepts into simple, easy-to-understand lessons. Perfect for anyone starting their JavaScript journey!

## Learning Path

The course is being updated to a new order. Follow the sessions in this order:

### Part 1: Basics

1. **[`01-introduction-to-javascript.md`](01-introduction-to-javascript.md)** - Getting started with JavaScript and Node.js
2. **[`02-variables-and-comments.md`](02-variables-and-comments.md)** - Variables (let, const, var), naming and comments
3. **[`03-data-types.md`](03-data-types.md)** - The 8 data types and typeof

5. **[`05-type-conversion.md`](05-type-conversion.md)** - Converting between strings, numbers and booleans
6. **[`06-conditionals.md`](06-conditionals.md)** - if, else, switch and the ternary operator

10. **[`10-functions.md`](10-functions.md)** - Parameters, return, default values, arrow functions, call stack and recursion
